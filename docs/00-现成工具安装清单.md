# 第 0 层：立即可用的现成工具（零代码，半天见效）

> 调研日期 2026-10-25，以下项目均已验证活跃/可用。它们与本仓库自研的 NameLens 插件（`idea-plugin/`）互补：
> 现成工具覆盖"通用解释/翻译/整库 wiki"，NameLens 补齐它们都做不到的 **命名逐词拆解、请求链路图、仓库术语表**。

## 1. IDEA 插件（必装）

### 1.1 通义灵码 或 CodeGeeX（二选一，免费）
| | 通义灵码 (Qoder CN) | CodeGeeX（智谱） |
|---|---|---|
| 安装 | IDEA → Settings → Plugins → Marketplace 搜 `TONGYI Lingma` | Marketplace 搜 `CodeGeeX` |
| 解释选中代码 | 选中 → 右键 → 灵码 → 解释代码 | 选中 → 悬浮灯泡/右键 → 解释代码 |
| 费用 | 个人免费 | 个人免费 |
| 缺点 | 不能自定义输出格式、不能换模型 | 同左 |

用途：日常"选中一段代码问什么意思"够用。**它不会做"命名逐词拆解"**（如 `resolveUserPrincipal` → 解析/用户/已认证主体），这正是 NameLens 插件的核心功能。

### 1.2 Translation（悬停翻译 JavaDoc）⭐读源码刚需
- Marketplace 搜 `Translation`（作者 YiiGuxing，11.9k star，MIT，持续维护）
- 用法：光标停在方法/类上 → `Ctrl+Q` 打开快捷文档 → 文档弹窗左下角地球图标翻译；也可选中按 `Ctrl+Shift+Y`
- 引擎设置里可选 OpenAI 兼容服务（即用 GLM/DeepSeek key 做翻译引擎）

## 2. 网站（看公开仓库，免部署）

| 站点 | 用法 | 说明 |
|---|---|---|
| [deepwiki.com](https://deepwiki.com) | 把仓库 URL 里 `github.com` 换成 `deepwiki.com` | 整库 wiki + 架构图 + Ask 追问（Cognition 出品，公开仓库免费） |
| [gitdiagram.com](https://gitdiagram.com) | 把 `github.com` 换成 `gitdiagram.com` | 一张可点击跳源码的交互架构图，1 分钟出图 |

例：读 Spring Security 源码 → 浏览器打开 `https://deepwiki.com/spring-projects/spring-security`

## 3. 私有仓库整库 wiki（可选，需 Docker + API Key）

见本目录 `deepwiki-open/`。自托管 deepwiki-open（MIT，18k star），配置 GLM/DeepSeek key 后，对公司私有 Spring 项目生成整库 wiki + 架构图。`docker compose up -d --build` 后访问 `http://localhost:3000`。

## 4. 运行时链路验证（可选）

- **Arthas**（阿里，Apache-2.0）：本地起服务后 `trace com.xxx.Controller 方法名`，看一次请求的真实调用链+耗时。NameLens 链路图是静态分析，反射/AOP 断链处建议用它确认。
